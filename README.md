# Распознавание чеков

Модуль `src/lib/receipt/` + прогонялка для проверки на реальных фото.

## Установка

```bash
npm install
```

(ставит `@anthropic-ai/sdk`, `sharp` и инструменты для запуска)

## Ключ API

Создай файл `.env` в корне (рядом с `package.json`):

```
ANTHROPIC_API_KEY=sk-ant-...
```

`.env` в репозиторий не коммитим.

## Проверить на фото чека

```bash
# один чек
npm run recognize -- cheque.jpg

# подсказать валюту поездки (не обязательно — модель определит и сама)
npm run recognize -- --currency=IDR grab.png

# длинный чек в несколько фото — это ОДИН чек, перечисли все файлы
npm run recognize -- page1.jpg page2.jpg
```

Скрипт ужмёт фото, отправит в Claude API, и напечатает: тип чека, валюту,
дату, позиции, сумму, итог, сошлась ли сверка и что нужно проверить вручную.

## Тесты (без API)

```bash
npm test
```

Проверяют разбор чисел по формату страны и сверку суммы с итогом — то, что
должно работать детерминированно и без обращения к модели.

## Из чего состоит

| Файл | Что делает |
|---|---|
| `src/lib/receipt/recognize.ts` | Вызов Claude API (vision). Здесь ужатие фото, кэш промпта, выбор модели. |
| `src/lib/receipt/prompt.ts` | Инструкция модели — все 10 правил распознавания. Кэшируется. |
| `src/lib/receipt/numbers.ts` | Разбор чисел с учётом формата страны (точка/запятая/пробел). |
| `src/lib/receipt/verify.ts` | Сверка суммы позиций с итогом, флаги «нужна проверка». |
| `src/lib/receipt/types.ts` | Типы результата (с заделом под мультиюзер — `ownerIds`). |
| `scripts/recognize.ts` | Прогонялка `npm run recognize`. |

Модель и предел на фото настраиваются через окружение:
`RECEIPT_MODEL` (по умолчанию `claude-haiku-4-5`).

## Запуск приложения (сервер + экран траты)

Слайс «сфоткал чек → позиции на экране». Нужно два терминала:

```bash
# 1) сервер распознавания (порт 8787)
npm run dev:server

# 2) экран (Vite, порт 5173) — проксирует /api на сервер
npm run dev:web
```

Открыть http://localhost:5173 → «Сфотографировать чек» → выбрать фото → позиции прилетают на экран.

### Режимы сервера (переменные окружения)
- `MOCK_RECOGNIZE=1` — демо-ответ без вызова API (крутить экран без ключа и без трат).
  Пример: `MOCK_RECOGNIZE=1 npm run dev:server`
- Боевой режим — просто `npm run dev:server`. Нужен рабочий `ANTHROPIC_API_KEY`
  в `.env` (ключ вида `sk-ant-api03-...` из console.anthropic.com).
- Демо прямо в экране без сервера: открыть http://localhost:5173/?demo=1

### Структура
- `src/lib/receipt/` — модуль распознавания (без изменений).
- `server/index.ts` — Fastify, эндпоинт `POST /api/recognize` (принимает фото, зовёт модуль).
- `web/` — экран траты (React + Vite).
- `scripts/sandbox-client.ts` — DEV-ONLY, только для прогона внутри песочницы Claude (прокси). В проде не используется.
